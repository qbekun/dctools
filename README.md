## Setup

### 1. Fork the repository
- Click **Fork** at the top of the page

### 2. Enable GitHub Pages
- Go to **Settings** → **Pages**
- Under **Source**, select **Deploy from a branch**
- Select **main** branch and **/** (root)
- Click **Save**
